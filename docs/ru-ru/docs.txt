================================================================================
 Sisyph — документация
================================================================================

Sisyph — императивный строко-ориентированный язык программирования.
Программа — это последовательность строк-команд, которые построчно выполняет
интерпретатор, написанный на Python (main.py).

Ключевая особенность: Sisyph не изобретает собственную арифметику и логику —
все выражения и значения переменных являются выражениями Python. Язык отвечает
за структуру программы (метки, переходы, подпрограммы), а вычисления
делегирует интерпретатору Python.

1. О ЯЗЫКЕ
--------------------------------------------------------------------------------
Имя                      : Sisyph
Расширение файлов        : .syh
Парадигма                : императивная, строко-ориентированная
Интерпретатор            : main.py (Python 3)
Выражения                : Python (eval / exec)
Типизация                : динамическая (типы Python)
Область видимости        : глобальная (единое пространство Python)

--------------------------------------------------------------------------------
2. ЗАПУСК ПРОГРАММ
--------------------------------------------------------------------------------
Запуск программы выполняется командой:

    python3 main.py программа.syh

Пример:

    python3 main.py a.syh

Если файл не найден, интерпретатор выводит сообщение об ошибке и завершает
работу.

Программу можно запустить и через компилятор BSYHC в режиме интерпретации
(см. раздел 13):

    python3 bsyhc.py -i программа.syh

--------------------------------------------------------------------------------
3. СИНТАКСИС
--------------------------------------------------------------------------------
Программа состоит из строк. Каждая строка содержит одну команду. Пустые
строки игнорируются.

Разделитель команд:
    Несколько команд можно записать в одну строку через точку с запятой:

        goto check; goto back

Метки:
    Метка — это имя строки, к которой можно перейти. Метка начинается с
    символа @ и занимает отдельную строку:

        @main
        stdlib.stdout "Привет!"

    Строки-метки при выполнении пропускаются.

Комментарии:
    Собственного синтаксиса комментариев в языке нет. Поскольку выражения
    обрабатываются Python, внутри выражений можно использовать символ #
    Python-комментария.

Регистр символов:
    Команды чувствительны к регистру: goto — команда, GOTO — нет.

Переменные:
    Переменные создаются неявно командами v.*, stdlib.stdin, file.* и
    pylib.*. Отдельного объявления не требуется. Имена переменных —
    обычные имена Python.

4. УПРАВЛЯЮЩИЕ КОМАНДЫ
--------------------------------------------------------------------------------
include
    Подключает файл библиотеки или встроенную библиотеку:

        include имя

    Если файл имя.syh существует, его строки добавляются в конец текущей
    программы, а метки файла становятся доступными с префиксом имя.метка:

        include lib
        goto lib.start

    Если файла нет, имя считается встроенной библиотекой. Встроенные
    библиотеки: stdlib, v, file, pylib.

goto
    Безусловный переход на метку:

        goto метка

    Позиция перехода сохраняется в стеке вызовов, поэтому впоследствии
    можно вернуться назад.

goto back
    Возврат из подпрограммы:

        goto back

    Берёт из стека вызовов позицию последнего перехода и продолжает
    выполнение с неё. Если стек пуст — выводится сообщение об ошибке.

    Пример подпрограммы:

        @main
        goto work
        exit 0

        @work
        stdlib.stdout "работаю..."
        goto back

exit
    Завершает программу:

        exit
        exit 0
        exit 5

    exit / exit 0      — успешное завершение, выводится сообщение
                         "The program has completed successfully."
    exit <код>         — завершение с кодом, выводится сообщение
                         "The program terminated with code \"<код>\"."

if
    Однострочное условное выполнение:

        if <выражение> then <команда>

    Если выражение истинно (приводится к bool в Python), выполняется команда
    после then. Конструкции else нет.

    Пример:

        if x > 10 then goto big
        if x <= 10 then goto small

--------------------------------------------------------------------------------
5. БИБЛИОТЕКА STDLIB
--------------------------------------------------------------------------------
Для использования подключите: include stdlib

stdlib.stdout
    Печать значения выражения:

        stdlib.stdout <выражение>

    Выражение вычисляется Python, поддерживаются f-строки:

        stdlib.stdout f"Значение: {x}"

stdlib.stdin
    Ввод строки с клавиатуры:

        stdlib.stdin <переменная> <подсказка>

    Результат сохраняется в переменную. Подсказка может быть строкой или
    выражением:

        stdlib.stdin name "Как тебя зовут? "

    Ввод без сохранения:

        stdlib.stdin <подсказка>

--------------------------------------------------------------------------------
6. БИБЛИОТЕКА V
--------------------------------------------------------------------------------
Для использования подключите: include v

Библиотека преобразует значение выражения в указанный тип и сохраняет
в переменную:

    v.int      целое число (int)
    v.str      строка (str)
    v.float    число с плавающей точкой (float)
    v.bool     логическое значение (bool)
    v.list     список (list)

Синтаксис:

    v.int x "42"
    v.list l [1, 2, 3]
    v.str s l[0]

--------------------------------------------------------------------------------
7. БИБЛИОТЕКА FILE
--------------------------------------------------------------------------------
Для использования подключите: include file

    file.read    <переменная> <путь>      читает файл целиком в переменную
    file.write   <путь> <выражение>       записывает выражение в файл (перезапись)
    file.append  <путь> <выражение>       дописывает выражение в конец файла
    file.delete  <путь>                   удаляет файл
    file.exists  <переменная> <путь>      сохраняет True/False о существовании файла
    file.lines   <переменная> <путь>      сохраняет список строк файла

Пример:

    file.write "data.txt" f"строка: {x}\n"
    file.read content "data.txt"
    file.exists ok "data.txt"

Если файл не удалось прочитать или удалить, выводится Sisyph File Error
с текстом исключения, а переменная получает значение по умолчанию
("" или []).

--------------------------------------------------------------------------------
8. БИБЛИОТЕКА PYLIB
--------------------------------------------------------------------------------
Для использования подключите: include pylib

Библиотека даёт прямой доступ к Python.

    pylib.exec       <код>                     выполняет произвольный Python-код
    pylib.eval       <переменная> <выражение>  вычисляет выражение и сохраняет результат
    pylib.import     <модуль>                  импортирует модуль Python
    pylib.importas   <модуль> <псевдоним>      импортирует модуль с псевдонимом
    pylib.from       <код>                     выполняет from <код>
    pylib.get        <переменная> <перем. Py>  копирует значение переменной Python
    pylib.set        <переменная Py> <выраж>   присваивает значение переменной Python
    pylib.print      <выражение>               вычисляет выражение и печатает результат

Пример:

    pylib.importas math m
    pylib.set x m.sqrt(16)
    pylib.print x

9. ПРИМЕРЫ ПРОГРАММ
--------------------------------------------------------------------------------
Пример 1. Списки и преобразование типов (a.syh)

    include v
    include stdlib

    v.list l ["po", 14, 17.3, True, ["object"]]
    v.str q l[0]
    v.str w l[1]
    v.str e l[2]
    v.str r l[3]
    v.str t l[4]
    v.str u l[4][0]
    stdlib.stdout f"{q}\n{w}\n{e}\n{r}\n{t}\n{u}\n"
    exit 0

Вывод:

    po
    14
    17.3
    True
    ["object"]
    object

Пример 2. Ввод, переходы и подпрограммы (b.syh)

    include v
    include stdlib

    v.str false_o "Ты не угадал("
    v.str true_o "Ты угадал!"

    @main
    stdlib.stdin sa "Введите строку: "
    v.str object "НИЧЕГО"
    goto check
    exit 0

    @check
    if sa == object then goto true
    if sa != object then goto false
    goto back

    @true
    stdlib.stdout true_o
    goto back

    @false
    stdlib.stdout false_o, "\n"
    goto main

Программа просит ввести строку, сравнивает её со словом «НИЧЕГО» и выводит
результат. Подпрограммы @true и @false возвращаются через goto back.

--------------------------------------------------------------------------------
10. ОГРАНИЧЕНИЯ И ОСОБЕННОСТИ
--------------------------------------------------------------------------------
- Нет циклов. Повторение организуется только через goto.
- Нет функций. Роль подпрограмм выполняют метки с goto / goto back.
- Нет локальных переменных. Всё хранится в глобальном пространстве Python.
- Нет else. Ветвление — только через if ... then.
- Однострочный if. Команда после then — одна, но может содержать ;.
- Разбор по пробелам и точкам. Аргументы, содержащие пробелы (например,
  пути файлов), разбираются небезопасно: file.write "my file.txt" x работать
  не будет.
- Общий стек вызовов. Рекурсивные переходы допустимы, но не ограничиваются.
- Выражения — это Python. Любая ошибка в выражении — это ошибка Python,
  а не Sisyph.
- include вставляет код. Подключённый файл добавляется в текущую программу
  и исполняется при достижении.

12. ЭКОСИСТЕМА
--------------------------------------------------------------------------------
- Файлы .syh — программы и библиотеки.
- include — механизм повторного использования: метки чужих файлов вызываются
  с префиксом имени файла (имя.метка).
- Встроенные библиотеки — stdlib (ввод/вывод), v (типы), file (файлы),
  pylib (Python).
- pylib — точка расширения: любой Python-код доступен из Sisyph без изменения
  интерпретатора.
- BSYHC — компилятор: bsyhc.py упаковывает .syh в самодостаточный .py, умеет
  декомпиляцию и мультифайловую сборку (см. раздел 13).
- Библиотеки языка — mathlib, strlib, listlib, randlib, timelib: подпрограммы
  для математики, строк, списков, случайностей и времени (см. раздел 14).

14. БИБЛИОТЕКИ ЯЗЫКА
--------------------------------------------------------------------------------
Вместе с языком поставляются библиотеки подпрограмм — обычные файлы .syh,
которые подключаются через include и вызываются через
goto <библиотека>.<подпрограмма>. Файлы лежат в каталоге lib/ и подключаются
без пути.

Соглашения:
    - Файл подключается командой include <имя>, подпрограмма вызывается
      goto <имя>.<подпрограмма>, возврат из подпрограммы — goto back.
    - Подпрограмма читает входные переменные (свой префикс у каждой
      библиотеки) и записывает результат в переменную <префикс>_result.
    - Данные передаются через глобальные переменные, поэтому перед каждым
      вызовом их нужно переустанавливать.
    - Внутри подпрограмм нет циклов: каждый goto кладёт позицию в стек
      вызовов, поэтому цикл внутри подпрограммы «засоряет» стек. Повторения
      организуются в основном коде программы.
    - Компилятор BSYHC может встроить библиотеки прямо в скомпилированный
      файл — см. раздел 13, флаг --merge include.

Пример:

    include v
    include stdlib
    include mathlib

    v.int ml_x 5
    goto mathlib.factorial
    stdlib.stdout f"5! = {ml_result}\n"
    exit 0

lib/mathlib.syh — математика (префикс ml_):

    mathlib.abs         ml_x                       -> ml_result  модуль числа
    mathlib.sign        ml_x                       -> ml_result  знак: -1, 0 или 1
    mathlib.min2        ml_a, ml_b                 -> ml_result  меньшее из двух
    mathlib.max2        ml_a, ml_b                 -> ml_result  большее из двух
    mathlib.clamp       ml_x, ml_lo, ml_hi         -> ml_result  ограничение границами
    mathlib.pow         ml_a, ml_b                 -> ml_result  a в степени b
    mathlib.is_even     ml_x                       -> ml_result  чётное ли число
    mathlib.is_odd      ml_x                       -> ml_result  нечётное ли число
    mathlib.factorial   ml_x                       -> ml_result  факториал
    mathlib.gcd         ml_a, ml_b                 -> ml_result  НОД

lib/strlib.syh — строки (префикс sl_):

    strlib.upper        sl_text                    -> sl_result  верхний регистр
    strlib.lower        sl_text                    -> sl_result  нижний регистр
    strlib.capitalize   sl_text                    -> sl_result  с заглавной буквы
    strlib.length       sl_text                    -> sl_result  длина строки
    strlib.strip        sl_text                    -> sl_result  без пробелов по краям
    strlib.reverse      sl_text                    -> sl_result  перевёрнутая строка
    strlib.contains     sl_sub, sl_text            -> sl_result  входит ли подстрока
    strlib.replace      sl_text, sl_old, sl_new    -> sl_result  замена подстроки
    strlib.split        sl_text, sl_sep            -> sl_result  разбиение на список
    strlib.join         sl_list, sl_sep            -> sl_result  склейка в строку
    strlib.is_digit     sl_text                    -> sl_result  только цифры?

lib/listlib.syh — списки (префикс ll_):

    listlib.length      ll_list                    -> ll_result  количество элементов
    listlib.sum         ll_list                    -> ll_result  сумма
    listlib.min         ll_list                    -> ll_result  минимум
    listlib.max         ll_list                    -> ll_result  максимум
    listlib.sort        ll_list                    -> ll_result  сортировка по возрастанию
    listlib.reverse     ll_list                    -> ll_result  обратный порядок
    listlib.unique      ll_list                    -> ll_result  без повторов
    listlib.contains    ll_item, ll_list           -> ll_result  есть ли элемент
    listlib.append      ll_list, ll_item           -> ll_result  с добавленным элементом
    listlib.range_n     ll_n                       -> ll_result  числа от 0 до n-1

lib/randlib.syh — случайности (префикс rl_):

    randlib.randint     rl_a, rl_b                 -> rl_result  случайное целое
    randlib.uniform     rl_a, rl_b                 -> rl_result  случайное число с плавающей точкой
    randlib.choice      rl_list                    -> rl_result  случайный элемент (строкой)
    randlib.shuffle     rl_list                    -> rl_result  перемешанная копия

lib/timelib.syh — время (префикс tl_):

    timelib.now         —                          -> tl_result  текущий timestamp
    timelib.strftime    tl_fmt                     -> tl_result  текущее время по формату
    timelib.sleep       tl_sec                     -> —          пауза на секунды

13. BSYHC — КОМПИЛЯТОР
--------------------------------------------------------------------------------
BSYHC (Base SisYpH Compiler, bsyhc.py) — компилятор языка Sisyph. Он упаковывает
.syh-файл в массив, в котором каждая новая строка — новый элемент массива,
встраивает в выходной файл копию интерпретатора и запускает программу уже из
массива. Скомпилированный .py-файл самодостаточен и не требует main.py рядом.

Режимы работы:

    Компиляция       python3 bsyhc.py -i b.syh -c -o bsyhc-test-b.py
    Декомпиляция     python3 bsyhc.py -i bsyhc-test-b.py -d -o b-de.syh
    Интерпретация    python3 bsyhc.py -i b.syh

Если указать только входной файл (без -c и -d), BSYHC просто интерпретирует
программу, как main.py.

Флаги:

    -i, --input <файл>    входной файл; может повторяться для компиляции
                          нескольких файлов в один выходной
    -o, --output <файл>   выходной файл (по умолчанию: <входной>.py / <входной>.syh)
    -c, --compile         скомпилировать .syh в самодостаточный .py
    -d, --decompile       декомпилировать скомпилированный .py обратно в .syh
    --merge concat|include  способ слияния файлов при компиляции
                          (по умолчанию concat)
    --split               при декомпиляции восстановить каждый исходный файл
                          отдельно (в каталог из -o)

Компиляция нескольких файлов:

    -i можно указывать несколько раз — все файлы соберутся в один выходной:

        python3 bsyhc.py -i main.syh -i lib.syh -c -o program.py

    --merge concat    строки файлов просто склеиваются по порядку.
    --merge include   первый файл — точка входа, остальные добавляются как
                      при include: их метки получают префикс имя_файла.метка
                      (например, goto lib.start).

Декомпиляция:

    Скомпилированный файл легко декомпилировать — программа восстанавливается
    из массива:

        python3 bsyhc.py -i bsyhc-test-b.py -d -o b-de.syh

    По умолчанию получается один объединённый .syh. С флагом --split каждый
    исходный файл восстанавливается отдельно в каталог, указанный через -o.
