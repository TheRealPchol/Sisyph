1. О языке

Sisyph — императивный строко-ориентированный язык программирования. Программа — это последовательность строк-команд, которые построчно выполняет интерпретатор, написанный на Python (main.py).

Ключевая особенность: Sisyph не изобретает собственную арифметику и логику — все выражения и значения переменных являются выражениями Python. Язык отвечает за структуру программы (метки, переходы, подпрограммы), а вычисления делегирует интерпретатору Python.

СвойствоЗначение
ИмяSisyph
Расширение файлов.syh
Парадигмаимперативная, строко-ориентированная
Интерпретаторmain.py (Python 3)
ВыраженияPython (eval / exec)
Типизациядинамическая (типы Python)
Область видимостиглобальная (единое пространство Python)

2. Запуск программ

Запуск программы выполняется командой:

python3 main.py программа.syh

Пример:

python3 main.py a.syh

Если файл не найден, интерпретатор выводит сообщение об ошибке и завершает работу.

Программу можно запустить и через компилятор BSYHC в режиме интерпретации (см. раздел 14):

python3 bsyhc.py -i программа.syh

3. Синтаксис

Программа состоит из строк. Каждая строка содержит одну команду. Пустые строки игнорируются.

Разделитель команд

Несколько команд можно записать в одну строку через точку с запятой:

goto check; goto back

Метки

Метка — это имя строки, к которой можно перейти. Метка начинается с символа @ и занимает отдельную строку:

@main
stdlib.stdout "Привет!"

Строки-метки при выполнении пропускаются.

Комментарии

Язык использует ~~ для комментариев. Всё, что идёт после ~~ в строке, игнорируется:

stdlib.stdout "привет" ~~ это комментарий

Дополнительно символ # можно использовать внутри выражений Python.

Регистр символов

Команды чувствительны к регистру: goto — команда, GOTO — нет.

Переменные

Переменные создаются неявно командами v.*, stdlib.stdin, file.* и pylib.*. Отдельного объявления не требуется. Имена переменных — обычные имена Python.

4. Управляющие команды

include

Подключает файл библиотеки или встроенную библиотеку:

include имя

Если файл имя.syh существует, его строки добавляются в конец текущей программы, а метки файла становятся доступными с префиксом имя.метка:

include lib
goto lib.start

Если файла нет, имя считается встроенной библиотекой. Встроенные библиотеки: stdlib, v, file, pylib, dc.

goto

Безусловный переход на метку:

goto метка

Позиция перехода сохраняется в стеке вызовов, поэтому впоследствии можно вернуться назад.

goto back

Возврат из подпрограммы:

goto back

Берёт из стека вызовов позицию последнего перехода и продолжает выполнение с неё. Если стек пуст — выводится сообщение об ошибке.

Пример подпрограммы:

@main
goto work
exit 0

@work
stdlib.stdout "работаю..."
goto back

exit

Завершает программу:

exit
exit 0
exit 5
  • exit / exit 0 — успешное завершение, выводится сообщение The program has completed successfully.
  • exit <код> — завершение с кодом, выводится сообщение The program terminated with code "<код>".

if

Однострочное условное выполнение:

if <выражение> then <команда>

Если выражение истинно (приводится к bool в Python), выполняется команда после then. Конструкции else нет.

Пример:

if x > 10 then goto big
if x <= 10 then goto small

5. Библиотека stdlib

Для использования подключите include stdlib.

stdlib.stdout

Печать значения выражения:

stdlib.stdout <выражение>

Выражение вычисляется Python, поддерживаются f-строки:

stdlib.stdout f"Значение: {x}"

stdlib.stdin

Ввод строки с клавиатуры:

stdlib.stdin <переменная> <подсказка>

Результат сохраняется в переменную. Подсказка может быть строкой или выражением:

stdlib.stdin name "Как тебя зовут? "

Ввод без сохранения:

stdlib.stdin <подсказка>

Для использования подключите include v.

Библиотека преобразует значение выражения в указанный тип и сохраняет в переменную:

7. Библиотека file

Для использования подключите include file.

КомандаНазначение
file.read <переменная> <путь>читает файл целиком в переменную
file.write <путь> <выражение>записывает выражение в файл (перезапись)
file.append <путь> <выражение>дописывает выражение в конец файла
file.delete <путь>удаляет файл
file.exists <переменная> <путь>сохраняет True/False о существовании файла
file.lines <переменная> <путь>сохраняет список строк файла

Пример:

file.write "data.txt" f"строка: {x}\n"
file.read content "data.txt"
file.exists ok "data.txt"

Если файл не удалось прочитать или удалить, выводится Sisyph File Error с текстом исключения, а переменная получает значение по умолчанию ("" или []).

Библиотека даёт прямой доступ к Python.

КомандаНазначение

9. Библиотека dc

Для использования подключите include dc.

Библиотека реализует классы данных — именованные словари, хранящие пары ключ-значение.

КомандаНазначение
dc.mkdc <имя>создаёт новый пустой класс данных
dc.set <имя>(<ключ> :: <значение>)устанавливает пару ключ-значение в классе данных
dc.get <переменная> <имя>(<ключ>)извлекает значение ключа и сохраняет в переменную
dc.remkey <имя> <ключ>удаляет ключ из класса данных
dc.move FROMDC(KEY) TODC(KEY)перемещает ключ из одного класса данных в другой (удаляя из источника)
dc.copy FROMDC(KEY) TODC(KEY)копирует ключ из одного класса данных в другой (источник остаётся)
dc.copy2var <переменная> <имя>(<ключ>)копирует значение ключа класса данных в переменную
dc.move2var <переменная> <имя>(<ключ>)перемещает значение ключа класса данных в переменную (ключ удаляется)

Синтаксис:

dc.mkdc a
dc.mkdc b
dc.set a(name :: "Alice")
dc.move a(name) b(name)
dc.copy b(name) a(name2)
dc.copy2var myvar b(name)
dc.move2var myvar2 a(name2)

Значение в dc.set вычисляется как выражение Python. При ошибке вычисления используется необработанная строка.

10. Примеры программ

Пример 1. Списки и преобразование типов (a.syh)

include v
include stdlib

v.list l ["po", 14, 17.3, True, ["object"]]
v.str q l[0]
v.str w l[1]
v.str e l[2]
v.str r l[3]
v.str t l[4]
v.str u l[4][0]
stdlib.stdout f"{q}\n{w}\n{e}\n{r}\n{t}\n{u}\n"
exit 0

Вывод:

po
14
17.3
True
["object"]
object

Пример 2. Ввод, переходы и подпрограммы (b.syh)

include v
include stdlib

v.str false_o "Ты не угадал("
v.str true_o "Ты угадал!"

@main
stdlib.stdin sa "Введите строку: "
v.str object "НИЧЕГО"
goto check
exit 0

@check
if sa == object then goto true
if sa != object then goto false
goto back

@true
stdlib.stdout true_o
goto back

@false
stdlib.stdout false_o, "\n"
goto main

Программа просит ввести строку, сравнивает её со словом «НИЧЕГО» и выводит результат. Подпрограммы @true и @false возвращаются через goto back.

11. Ограничения и особенности

  • Нет циклов. Повторение организуется только через goto.
  • Нет функций. Роль подпрограмм выполняют метки с goto / goto back.
  • Нет локальных переменных. Всё хранится в глобальном пространстве Python.
  • Нет else. Ветвление — только через if ... then.
  • Однострочный if. Команда после then — одна, но может содержать ;.
  • Разбор по пробелам и точкам. Аргументы, содержащие пробелы (например, пути файлов), разбираются небезопасно: file.write "my file.txt" x работать не будет.
  • Общий стек вызовов. Рекурсивные переходы допустимы, но не ограничиваются.
  • Выражения — это Python. Любая ошибка в выражении — это ошибка Python, а не Sisyph.
  • include вставляет код. Подключённый файл добавляется в текущую программу и исполняется при достижении.

13. Экосистема

  • Файлы .syh — программы и библиотеки.
  • include — механизм повторного использования: метки чужих файлов вызываются с префиксом имени файла (имя.метка).
  • Встроенные библиотеки — stdlib (ввод/вывод), v (типы), file (файлы), pylib (Python), dc (классы данных).
  • pylib — точка расширения: любой Python-код доступен из Sisyph без изменения интерпретатора.
  • BSYHC — компилятор: bsyhc.py упаковывает .syh в самодостаточный .py, умеет декомпиляцию и мультифайловую сборку (см. раздел 14).
  • Библиотеки языка — mathlib, strlib, listlib, randlib, timelib: подпрограммы для математики, строк, списков, случайностей и времени (см. раздел 15).

15. Библиотеки языка

Вместе с языком поставляются библиотеки подпрограмм — обычные файлы .syh, которые подключаются через include и вызываются через goto <библиотека>.<подпрограмма>. Файлы лежат в каталоге lib/ и подключаются без пути.

Соглашения

  • Файл подключается командой include <имя>, подпрограмма вызывается goto <имя>.<подпрограмма>, возврат из подпрограммы — goto back.
  • Подпрограмма читает входные переменные (свой префикс у каждой библиотеки) и записывает результат в переменную <префикс>_result.
  • Данные передаются через глобальные переменные, поэтому перед каждым вызовом их нужно переустанавливать.
  • Внутри подпрограмм нет циклов: каждый goto кладёт позицию в стек вызовов, поэтому цикл внутри подпрограммы «засоряет» стек. Повторения организуются в основном коде программы.
  • Компилятор BSYHC может встроить библиотеки прямо в скомпилированный файл — см. раздел 14, флаг --merge include.

Пример

include v
include stdlib
include mathlib

v.int ml_x 5
goto mathlib.factorial
stdlib.stdout f"5! = {ml_result}\n"
exit 0

14. BSYHC — компилятор

BSYHC (Base SisYpH Compiler, bsyhc.py) — компилятор языка Sisyph. Он упаковывает .syh-файл в массив, в котором каждая новая строка — новый элемент массива, встраивает в выходной файл копию интерпретатора и запускает программу уже из массива. Скомпилированный .py-файл самодостаточен и не требует main.py рядом.

Режимы работы

РежимКоманда
Компиляцияpython3 bsyhc.py -i b.syh -c -o bsyhc-test-b.py
Компиляция в ELFpython3 bsyhc.py -i b.syh -c -elf -o b_bin
Компиляция в EXEpython3 bsyhc.py -i b.syh -c -exe -o b.exe
Промежуточный .pypython3 bsyhc.py -i b.syh --py -o app.py
Декомпиляцияpython3 bsyhc.py -i bsyhc-test-b.py -d -o b-de.syh
Декомпиляция бинарникаpython3 bsyhc.py -i b_bin -d -o b-de.syh
Интерпретацияpython3 bsyhc.py -i b.syh

Если указать только входной файл (без -c и -d), BSYHC просто интерпретирует программу, как main.py.

Флаги

ФлагНазначение
-i, --input <файл>входной файл; может повторяться для компиляции нескольких файлов в один выходной
-o, --output <файл>выходной файл (по умолчанию: <входной>.py / <входной>.syh)
-c, --compileскомпилировать .syh в самодостаточный .py
--pyсгенерировать только промежуточный самодостаточный .py для ручной сборки через PyInstaller (печатает точную команду PyInstaller)
-elfскомпилировать .syh в бинарный файл ELF через PyInstaller (Linux)
-exeскомпилировать .syh в бинарный файл EXE через PyInstaller (Windows)
-k, --keep-intermediateпри сборке бинарника (-c -elf / -c -exe) сохранить промежуточный .py рядом с бинарником (как <выход>.py) и напечатать команду PyInstaller для ручной пересборки
-d, --decompileдекомпилировать скомпилированный .py (или бинарник BSYHC) обратно в .syh
--merge concat | includeспособ слияния файлов при компиляции (по умолчанию concat)
--splitпри декомпиляции восстановить каждый исходный файл отдельно (в каталог из -o)

Компиляция нескольких файлов

-i можно указывать несколько раз — все файлы соберутся в один выходной:

python3 bsyhc.py -i main.syh -i lib.syh -c -o program.py
  • --merge concat — строки файлов просто склеиваются по порядку.
  • --merge include — первый файл — точка входа, остальные добавляются как при include: их метки получают префикс имя_файла.метка (например, goto lib.start).

Компиляция в бинарный файл (ELF / EXE)

BSYHC умеет собирать программу в бинарный файл через PyInstaller (--onefile):

python3 bsyhc.py -i b.syh -c -elf -o b_bin
python3 bsyhc.py -i b.syh -c -exe -o b.exe
  • -elf — бинарный файл ELF (сборка под Linux).
  • -exe — бинарный файл EXE (сборка под Windows).
  • Требуется установленный PyInstaller (pip install pyinstaller); проект может использовать собственное окружение env/.
  • Сборка идёт во временном каталоге: build/, dist/, *.spec и промежуточный .py удаляются автоматически — остаётся только готовый бинарник.
  • PyInstaller не умеет кросс-компиляцию: на Linux -exe даст нативный бинарник с именем *.exe, а настоящий Windows-EXE собирается только в Windows.
  • Бинарник, собранный BSYHC, можно декомпилировать обратно в .syh (см. ниже).

Промежуточный .py (ручная сборка через PyInstaller)

Компиляция с -c даёт самодостаточный .py — это и есть промежуточное представление, которое PyInstaller превращает в бинарник для -elf / -exe. Режим --py генерирует его явно и печатает команду PyInstaller, чтобы собрать бинарник вручную:

python3 bsyhc.py -i b.syh --py -o app.py
pyinstaller --onefile --noconfirm --name app app.py

При обычной сборке бинарника промежуточный .py живёт во временном каталоге и удаляется после сборки. Флаг -k сохраняет его рядом с бинарником:

python3 bsyhc.py -i b.syh -c -elf -o b_bin -k   # b_bin + b_bin.py

Декомпиляция

Скомпилированный файл легко декомпилировать — программа восстанавливается из массива:

python3 bsyhc.py -i bsyhc-test-b.py -d -o b-de.syh

По умолчанию получается один объединённый .syh. С флагом --split каждый исходный файл восстанавливается отдельно в каталог, указанный через -o.

Декомпилировать можно не только .py, но и собранный бинарник — BSYHC извлекает исходный массив из кода, встроенного в бинарник:

python3 bsyhc.py -i b_bin -d -o b-de.syh
